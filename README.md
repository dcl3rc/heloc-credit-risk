# HELOC credit risk classification

Learning project: benchmarking classifiers on the FICO HELOC dataset,
starting with penalised logistic regression and kernel SVM.

## Data

Not included in the repository. Download `heloc_dataset_v1.csv` from
https://www.kaggle.com/datasets/averkiyoliabev/home-equity-line-of-creditheloc
and place it in `data/`.

Column meanings and special codes: `docs/data_dictionary.md`.

## Structure

    data/   raw data (git-ignored)
    docs/   data dictionary
    src/    code

## Status

Data preparation complete. Exploratory analysis in progress.
